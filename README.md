# Founder skill

Les 11 skills de [Jakeschincariol/founder-skill](https://github.com/Jakeschincariol/founder-skill)
(licence MIT), installés en local au projet dans `.claude/skills/`.

Commandes : `/founder-board`, `/founder-competitors`, `/founder-consumer`,
`/founder-pricing`, `/founder-offer`, `/founder-cfo`, `/founder-marketing`,
`/founder-brand`, `/founder-ops`, `/founder-launch`, `/founder-plan`.

Ordre conseillé : board → competitors → consumer → pricing → offer → cfo →
marketing → brand → ops → launch → plan. Les résultats sont écrits dans `founder/`.
